# Full Stack Project

This project contains a `backend` (Node.js + Express) and a `frontend` (React) application.

## Setup Instructions

### Backend

1. Open terminal
2. Run:
    ```bash
    cd backend
    npm install
    npm start
    ```

### Frontend

1. Open terminal
2. Run:
    ```bash
    cd frontend
    npm install
    npm start
    ```
